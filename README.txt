THE ART FACTORY - WEBSITE PROJECT
=================================

A responsive 4-page website for The Art Factory, Tiruppur.

PAGES
- index.html       Home
- services.html    Drawing, wall art, framing and architecture-inspired art
- gallery.html     Illustrative art gallery
- contact.html     Contact details and artist opportunities/enquiry form

HOW TO RUN
1. Extract the ZIP folder.
2. Open the_art_factory_website/index.html in a browser.
3. Use the navigation menu to visit all four pages.

CUSTOMISE
- Edit text and contact details in the HTML files.
- Change colours and layout in assets/style.css.
- Change mobile navigation and enquiry form behaviour in assets/script.js.

FORM NOTE
The enquiry form opens the visitor's default email application and prepares an email
to artfactorytiruppur@gmail.com. It does not store submissions on a server.
The gallery artwork is made from original inline SVG illustrations and is illustrative.
